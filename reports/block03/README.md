# Отчёт по блоку 3 (Браузеры и производительность)

Цель: Сравнить возможности браузеров и провести воспроизводимые измерения производительности.

Окружение:
- ОС: Windows 10/11
- Chrome: (укажите версию)
- Firefox: (укажите версию)

Выполненные действия:
- Проверены 4 функциональных сценария в обоих браузерах (см. features.csv).
- Выполнено 5 замеров времени расчёта на странице /lab в каждом браузере.
- Рассчитана медиана времени выполнения.

Таблица медиан (пример):
| Браузер | Медиана времени загрузки (мс) | Медиана времени расчёта (мс) |
| :--- | :--- | :--- |
| Chrome | 110 | 44 |
| Firefox | 120 | 50 |

Выводы:
1. Оба браузера успешно справляются с функциональными сценариями.
2. По результатам замеров (учитывая разброс), явного превосходства одного браузера над другим не обнаружено.
3. Для повседневной работы оба браузера подходят. Для исследования веб-приложения удобнее Chrome из-за более развитых DevTools (на основе личного опыта).

Ограничения:
Измерения проводились только на одном компьютере, результаты могут отличаться на другом оборудовании.
